# EICT Summer Training Projects

This repository contains web development projects created during the EICT Summer Training:

- **[Calculator](./Calculator)**: A clean and responsive calculator web application built with HTML, CSS, and JavaScript.
- **[To-Do List](./To-Do-List)**: A feature-rich To-Do List application built with HTML, CSS, and JavaScript.
- **[Login and Registration](./Login%20and%20Registration)**: A full-stack user authentication system built with Node.js, Express, MongoDB, and EJS.
